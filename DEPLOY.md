# 4Levels Sports Advisory: how to push, deploy and launch

**Updated 17 Oct 2026.** This replaces the Aug 16 one-page version.

The site is static HTML. Every page is generated by `_build/build.py` from `_build/data.py`.
**Never hand-edit the `.html`, `.md`, `llms*.txt` or `agents.md` files.** Edit `data.py`, then rebuild.

| What you change | Run |
|---|---|
| Any words, team, clients, switches | `python3 _build/build.py` (works on the Mac) |
| Any image (logo, photos, share cards) | `python3 _build/assets.py` then `python3 _build/build.py`. This needs Pillow, so run it in the Claude cloud workspace, not on the Mac. |
| Check everything | `python3 -m http.server 8765` in one terminal, then `python3 _build/check.py` (cloud workspace, needs Playwright) |

## 1. Push (Cursor terminal, in this folder)

The repo already exists: `github.com/ryderai/4-levels`.

```
cd ~/Documents/AI-Syndicate/4Levels-Sports-Advisory
rm -f .git/*.lock
git add -A
ID=$(gh api users/ryderai --jq .id)
git -c user.name=ryderai -c user.email="${ID}+ryderai@users.noreply.github.com" commit -m "4Levels site v2: multi-page build from the client deck"
git push origin HEAD
```

The commit is signed as ryderai on purpose: Vercel blocks deploys from commits signed by your Mac's default email. If the push says 403, run `gh auth switch` and pick `ryderai`.

## 2. Deploy on Vercel (first time only)

1. Go to vercel.com and open the **aisyndicate** team.
2. Click **Add New…**, then **Project**.
3. Pick the repo **ryderai/4-levels** and click **Import**.
4. For Framework Preset, choose **Other**. Leave Root Directory as `./`. Leave the build command empty.
5. Click **Deploy**.
6. When it's done, copy the address it gives you.
   - **If it is not `https://4-levels.vercel.app`**, open `_build/data.py` and set `PUBLIC_URL` to the real address.
   - Then run `python3 _build/build.py`, commit and push again. Otherwise the link-preview cards come up blank.

## 3. Check the preview

- Open the address on your phone and tap **Menu**.
- Paste the address into https://www.opengraph.xyz and check that the dark 4Levels card shows.
- Open `/llms.txt` and `/index.md` and check that both load.

## 4. Connect the contact form (blocked until 4Levels gives an email)

The form shows "This form is not connected yet" until these are set.

1. In Vercel, open the project, then **Settings**, then **Environment Variables**.
2. Add `RESEND_API_KEY`, the key from our Resend account.
3. Add `LEAD_FROM_EMAIL` with the value `4Levels Website <leads@contact.aisyndicate.com>`.
4. Add `LEAD_TO_EMAIL`. This is **blocked: we don't have 4Levels' email yet.**
5. Optionally, add `LEAD_BCC_EMAIL` with the value `growth@aisyndicate.com`.
6. Go to **Deployments**, click **⋯** on the newest one, then click **Redeploy**. Changes to these settings do nothing until you redeploy.
7. Open `https://<site>/api/lead?diag=1`. It says in plain words whether the settings are right.
8. Then send one real test from the form.

## 5. Launch day (blocked until 4Levels approves and a domain exists)

1. In `_build/data.py`, set `PUBLIC_URL` to the real domain and `PRELAUNCH = False`.
2. Fill in `EMAIL`, `PHONE` and `CITY`.
3. Add the geo tags in `build.py` `head()` once the city is known.
4. Run `python3 _build/build.py`, then commit and push.
5. That one switch removes the noindex tags, the "Design preview" bar and the `Disallow` in robots.txt.
6. Add the domain in Vercel under Settings, then Domains.
7. Submit the site to Google Search Console, Bing and IndexNow.
8. Run a platform scan for the baseline score.

## Adding clients (the Clients page)

In `_build/data.py`, fill `CLIENTS` with one entry per athlete:

```
CLIENTS = [
    {"name": "First Last", "hometown": "City, ST", "team": "School or team", "img": "/assets/img/clients/first-last.jpg"},
]
```

- Put each headshot in `assets/img/clients/` at 800×1000.
- Headshots taken from team websites need permission before launch.
